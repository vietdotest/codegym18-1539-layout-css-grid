# CSS Grid Layout

Header, Sidebar, Main Content, Footer đặt tên bằng grid-area. Desktop 1fr/3fr; <=768px xếp dọc; min-height thay height cố định để nội dung dài không tràn.

## Chạy
Mở index.html trong trình duyệt. Các ví dụ có kích thước cố định được đặt trong khung cuộn ở màn hình nhỏ để giữ đúng giá trị thuộc tính.
